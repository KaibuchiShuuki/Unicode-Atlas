使用教程

      

        
      

    

    


      

        
这是什么

        
一个离线的 Unicode 字符百科全书：把某一版 Unicode 的全部字符（含未分配码点）按官方分类摊开，让你看、查、挑、复制。

        
数据来自 unicode.org 的 UCD 原始文本文件，下载一次就存在本地 data/ 里，之后断网也能用。

      


      

        
① 怎么找字符

        
    
          
  • 左栏五种索引：分类（Lu/Ll/Lo…，按 L/M/N/P/S/Z/C 分组）、区块（353 个 Unicode 块）、文字系统（Han/Latin/Arabic…）、引入版本（1.1 起每个版本各有多少）、平面（BMP/SMP/SIP/TIP/SSP/私用区）。
    • 
          
  • 顶部搜索框：输入名字（heart、龙、微笑）、码点（U+4E2D、0x4e2d、4E2D）、或者直接粘贴一个字符。前 200 条按匹配度排序，之后接全量列表。
    • 
          
  • 快捷键 / 跳到搜索框，Esc 关闭弹窗。
    • 
          
  • 左栏顶部的筛选框只过滤索引列表本身，不影响中间网格。
    • 
        

      


      

        
② 方格怎么看

        
    
          
  • 格子 = 字形 + 码点。滚动到底部自动加载下一页（每页 200 个）。
    • 
          
  • 控制字符显示缩写（NUL、CR、HT…），因为它们本来就没有字形。
    • 
          
  • 蓝紫字是私用区（PUA），虚线圆框是组合附加符号，空白是尚未分配。
    • 
          
  • 鼠标停留 0.4 秒弹出预览卡：字形、名字、码点、类别、区块、引入版本、中文释义与拼音。
    • 
          
  • 方格上没有加号也没有双击——拿走字符一律走详情页的按钮，避免误操作。
    • 
        

      


      

        
③ 右边：收集框 + 字符档案

        
    
          
  • 收集框：详情页点「加入收集框」，字符按顺序排成 chip，底部自动拼成一串文本，点「复制」即可带走。同一个字符可以加很多次，点 chip 的 × 按位置删。
    • 
          
  • 字符档案：编码（UTF-8/UTF-16/十进制）、类别、区块、文字系统、引入版本、组合类别、双向类别、分解、数值、大小写映射、EAW、断行、别名、注释、CLDR 中文、Unihan（汉字读音/释义/笔画/异体）。
    • 
        

      


      

        
④ 字形栏：一个字有好几种样子

        
每个字符的详情里都有「字形（N）」区，把同一字符的所有写法并排列出：

        
    
          
  • 阿拉伯文的独立形/词首形/词中形/词尾形，蒙古文的变体序列；
    • 
          
  • CJK 兼容汉字、全角/半角、上标下标、带圈带框；
    • 
          
  • Unihan 的简体/繁体/兼容/语义异体；
    • 
          
  • 汉字另加中日韩三种标准字形。
    • 
        

        
每张卡只有一个「复制」按钮：复制原形还是完整变体序列（基础字符 + 不可见的变体选择符），由卡片决定。历史一律记在原形码点名下。

      


      

        
⑤ 版本：历代 Unicode 都在

        
    
          
  • 设置菜单里的下拉框切换当前查看的版本，可同时装多个版本（例如 18.0.0 与 15.1.0），互不影响。
    • 
          
  • 「检查更新」探测 unicode.org 的最新版；「版本管理…」列出已装版本、可安装历史版本（1.1 起）、显示每个版本缺了哪些数据文件。
    • 
          
  • 老版本没有 Unihan/CLDR 是正常的：那些文件当年还不存在。
    • 
        

      


      

        
⑥ 字体：让每个字都显示出来

        
    
          
  • 系统字体缺字时格子会显示方框（豆腐块）。到「版本管理 → Noto 字体包」一键下载，206 个 Noto 字体覆盖绝大多数码点。
    • 
          
  • 程序目录下的 vendor/fonts/ 存着一份字体备份，装包时优先从这里复制，断网也能补。
    • 
          
  • Emoji 可以在设置里选「Noto 单色」或「系统彩色」。
    • 
          
  • 少数最新字符 Noto 还没做（例如小篆、遗产计算符号补充），这些只能等字体厂商更新。
    • 
        

      


      

        
⑦ 花体英文生成器

        
设置 →「花体英文生成器…」，输入拉丁字母或数字，实时给出 18 种风格：粗体、斜体、花体、哥特体、空心体、圆圈、方框、全角、上标、下标、倒置……每行一个复制按钮。这些是 Unicode 里各自独立编码的字形，复制到任何地方外观都不变。

      


      

        
⑧ 中英切换与历史

        
    
          
  • 设置 →「中 / EN」把区块、文字系统、类别名在中文与英文之间切换，选择会记住。
    • 
          
  • 「历史」记录所有真正被拿走的动作（加入收集框、复制原形、复制变体序列），不记录只是点开看看的字符；上限 300 条，可单条删或清空。
    • 
        

      


      

        
⑨ 常见问题

        
    
          
  • 显示方框：缺字体，去装 Noto 字体包。
    • 
          
  • 浏览器提示「现有实例正在以提升的权限运行」：有一份以管理员身份启动的浏览器在跑，点「是」重启为普通权限即可，服务本身没问题。
    • 
          
  • 能离线吗：装好版本和字体之后完全可以，程序不联网也能跑。
    • 
          
  • 关不掉：设置 →「关闭程序」，服务会退出；下次双击 启动 Unicode-Atlas.pyw 重新启动。
    • 
        

      


    

  







  

    

      
关于 Unicode-Atlas

      

        
      

    

    

      

        
        

          
Unicode-Atlas

          
离线 Unicode 字符百科全书

          
版本 1.0 · 当前数据 —

        

      


      

        
数据来源

        
    
          
  • UCD（Unicode Character Database）：UnicodeData.txt、Blocks.txt、Scripts.txt、DerivedAge.txt、DerivedName.txt、NameAliases.txt、CaseFolding.txt、SpecialCasing.txt、PropList.txt、EastAsianWidth.txt、LineBreak.txt、NamesList.txt、StandardizedVariants.txt 等，直接取自 unicode.org，按版本分别保存。
    • 
          
  • Unihan：汉字的读音、释义、笔画、异体、简繁对应。
    • 
          
  • CLDR（cldr-annotations-full）：字符的中文与英文注释、关键词。
    • 
          
  • Noto 字体：Google 的 Noto 家族，覆盖 200 多种文字系统。
    • 
        

      


      

        
技术

        
    
          
  • 后端：Node.js 内置模块，零第三方依赖，不需要 npm install。
    • 
          
  • 前端：原生 HTML/CSS/JavaScript，无框架、无构建步骤。
    • 
          
  • 数据全部落在程序目录的 data/ 下：versions/<版本>/ 存原始 UCD 文本与压缩索引，fonts/ 存字体。
    • 
          
  • 只监听回环地址 127.0.0.1，不向外网暴露任何端口。
    •
